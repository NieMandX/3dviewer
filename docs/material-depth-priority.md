# Z-приоритет материала

В панели «Объекты» → файл → материал есть поле **Z-приоритет**, от −8 до +8.
Начинать следует с +1 для покрытия, которое должно быть видно поверх соседнего
слоя, или с −1 для скрываемого слоя. Ноль восстанавливает исходные настройки.
Изменение применяется ко всем объектам, использующим именно этот экземпляр
материала, в режиме PBR. Материалы с одинаковым именем могут быть разными
экземплярами и автоматически не объединяются.

Настройка действует **в текущей загрузке модели**. Она не записывается в исходный
GLB, комнату или экспорт. Переключение диагностического режима и возврат в PBR
сохраняет настройку; повторный импорт начинает с исходного состояния.

Реализация использует `polygonOffset` с `factor = -priority`, `units = -4 * priority`
для обычного буфера глубины WebGPU и WebGL. Геометрия, координаты, `renderOrder`,
`depthTest` и `depthWrite` не изменяются. Приоритет не является смещением в метрах.
Если в будущем включается reversed depth, знак смещения надо перепроверить для
обоих backend. Состояние хранится в WeakMap, не удерживая удалённые материалы.

В закреплённом Three.js r184 WebGPUBackend не учитывает `polygonOffset` в ключе
кэша pipeline и проверке изменения состояния. `depth-bias-cache.js` дополняет
оба метода только у текущего WebGPU backend после его инициализации и восстанавливает
их при disposal. Это предотвращает использование одного pipeline материалами
с разными смещениями. WebGL backend не изменяется. При обновлении Three.js этот
обход нужно сверить с исправлениями upstream и повторить проверку рендеринга.

Это средство для почти совпадающих поверхностей с разными материалами. Оно не
разделяет дубли внутри одного материала и не исправляет сортировку прозрачности.
Большие значения могут давать неверные перекрытия на скользящих углах, поэтому
используется минимальное достаточное значение. Всем материалам автоматически
приоритеты не назначаются: требуемый порядок покрытий определяется по модели.

Проверка `smoke-depth-priority.mjs` проверяет итоговый цвет перекрывающихся
плоскостей, сохранение обычного перекрытия передним объектом, общий материал,
возврат к исходному offset, диагностический материал и устаревшие UI-события.
