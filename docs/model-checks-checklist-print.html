3.1 Высокополигональные модели (ВПМ / SM)

РазделПроверки
Текстуры и UDIMУпаковка текстур; обязательный набор Diffuse/ERM/Normal; целостность нумерации UDIM; допустимые разрешения и квадратность; согласованность разрешений в UDIM-плитке; неиспользуемые текстуры; выход UV за границы; texel density.
ГеометрияТрансформации (location/rotation/scale); лимит полигонов ОКС; лимит полигонов UCX; триангуляция (без n-gon); дубликаты вершин; изолированные вершины/рёбра/грани.
Состав FBXЛишние объекты/анимации/камеры/коллекции; обязательность UCX; ограничение на количество мешей стекла; иерархические связи между мешами; отдельная логика для light-FBX.
МатериалыНаличие UV у обычных и glass-объектов; запрет UV у UCX; лимит материалов (общий/glass); отсутствие материала у UCX; наличие материала у основных мешей; ограничения для Main в зависимости от количества UDIM; SlotNumber _1.._N; проверка лишних ссылок в BSDF; запрет текстур в glass-материалах.
Коллизии UCXЗамкнутость, выпуклость, нумерация коллизий, пересечения коллизий между собой.
ОсвещениеТипы источников (POINT/SPOT), иерархия с Root, лимит количества (до 250), анализ минимальных расстояний между светильниками с учётом типа пары.
GeoJSONНаличие/кодировка/структура; обязательные поля и типы; проверка FNO-кода по классификатору; валидность значений; кавычки/апостроф; единообразие общих полей между ОКС и Ground; наличие и структура блока Glasses; соответствие материалов стекла данным geojson.
PNGПодтверждение формата PNG; RGB-режим; отсутствие alpha у ERM/Normal; правила для заглушек 256 (одноцветность, alpha); поиск одноцветных «не-заглушек».
ИменованиеНедопустимые символы/длина; строгие маски имён для zip/fbx/geojson, мешей (Main/Ground/UCX), материалов, текстур, источников света (Omni/Spot/Root).
АдресПроверка сокращений (171н), допустимых символов, формата, регистра, подчёркиваний, кадастрового номера, латиницы/транслитерации, соответствия адреса Ground и ОКС.
Pivot и служебныеПроверка смещения точки отсчёта; проверка color attributes в FBX; проверка состава архива (кол-во fbx/png/geojson и их наличие).

Примечание: проверка «зеркальные острова UV» в коде есть, но сейчас фактически отключена (возвращает пустой результат).

3.2 Низкополигональные модели (НПМ)

РазделПроверки
ИменованиеМаски имен zip/fbx/мешей/материалов/текстур; согласование адреса с Ground; имя texture-node должно совпадать с именем файла.
ГеометрияТрансформации; лимиты полигонов (Ground и не-Ground раздельно); триангуляция; дубликаты/изолированные элементы.
UV и texelПлотность пикселей для Ground-поверхности с учётом разрешения базовой карты.
FBX-составКоличество fbx (лимит), наличие обязательного Ground, отсутствие лишних объектов/анимаций/камер/коллекций, запрет mesh-иерархий.
Материалы и текстурыЛимиты материалов (благо, стекло, обычные); единый размер текстур в материале; лимит размеров для элементов благоустройства; запрет текстур в стекле; ограничения для Flora (обязательный diffuse, запрет metallic/roughness); контроль веса текстур.
АдресТот же блок адресной валидации, что и для ВПМ (сокращения, формат, символы, кадастр, регистр и т.д.).
