# Редактор материалов

Вкладка **Материалы** в правой панели показывает уникальные материалы загруженных моделей. Общий материал редактируется сразу на всех использующих его объектах. Карточки рисуются по мере появления в списке тем же renderer, без второго контекста и постоянного цикла миниатюр.

Доступны PBR-параметры, карты цвета/normal/roughness/metalness/AO/emissive, Z-приоритет и пресеты воды, стекла, травы, камня и кирпича. Пресеты поверхностей содержат процедурные повторяемые карты; это стартовые образцы, а не замена подготовленным текстурам M8. Вода и стекло используют согласованные параметры.

Изменение цвета, цвета свечения и затухания обновляет uniform-параметры без принудительной пересборки шейдера сцены. У миниатюр отдельная версия правки: обновляется нужная карточка, а незавершённое чтение старого изображения не может перезаписать новый цвет. Структурные изменения материала по-прежнему обновляют программу рендеринга.

## Пипетка

Нажмите **Пипетка — выбрать на модели**, затем щёлкните по поверхности в окне вида. Открывается её материал; фильтр списка сбрасывается, если скрывал выбранную карточку. У объектов с несколькими материалами выбирается слот пересечённой грани, у инстансов — материал соответствующего меша. Скрытые объекты и коллизии не участвуют. Выбор действует и в режиме сравнения с исходными материалами, не меняя назначения.

Это однократный выбор: после попадания управление камерой возвращается. Esc, повторное нажатие, закрытие вкладки, смена комнаты или состава моделей отменяют пипетку. Перетаскивание не считается щелчком. Во время рисования аннотаций инструмент не запускается. На узком экране панель временно перемещается вниз, освобождая окно вида.

## Исходные и изменённые

Импортёр сохраняет отдельный набор материалов сразу после парсинга GLB/FBX, до адаптации шейдеров вьюером. Переключатель **Исходные / Изменённые** не уничтожает правки. Исходные материалы не редактируются напрямую; для показа создаются копии. Геометрия не копируется, неизменённые текстуры разделяются. Служебные ссылки не попадают в JSON extras и учитываются при удалении модели.

**Вернуть исходный** сбрасывает выбранный материал. **Отменить правку** возвращает последнее изменение выбранного материала. Правки в других диагностических режимах переводят показ в PBR.

## Течение

**Нарисовать течение** включает расстановку точек raycast-ом только по объектам выбранного материала. Точки сохраняются в координатах сцены без визуального rebase контейнера `world`. Перетаскивание также проецируется на водную поверхность. Точки соединяются сглаженной кривой со стрелками.

Для развилки нажмите **Выбрать начало ветки**, выберите существующую точку и добавьте новую цепочку. Щелчок по существующей конечной точке соединяет ветки. Можно удалить выбранную точку с её связями, развернуть направления или отменить черновик. **Применить течение** создаёт поле направлений для анимации нормалей; форма реки и её геометрия не меняются. Это художественное управление движением поверхности, не гидродинамический расчёт препятствий.

Контракт воды версии 2 использует координаты XZ, сеть `nodes/edges` и карту направлений. Версия 1 исходного M8 по-прежнему читается с прежними UV. WebGPU использует TSL, WebGL — эквивалентный shader hook. Анимация просит кадры через основной `requestRender()` и останавливается для скрытого/удалённого материала или нулевой скорости.

## Настройки комнаты

**Сохранить в комнате** сохраняет только параметры изменённых материалов: цвет, PBR-свойства, прозрачность, Z-приоритет, скорость/паузу воды и точки с соединениями течения. Изображения, карты течения, ссылки на наборы, код шейдеров и геометрия не записываются в облако. Описание шейдера воды реализовано самим вьюером; сеть направлений восстанавливается из точек.

Документ `lpmview-materials`, версия 1, имеет признак `settingsOnly` и поле `settings` в каждой строке. Привязка — ID модели комнаты и постоянный ID исходного материала. Для локального файла используется его имя. При применении параметров имеющиеся текстуры модели/открытого набора сохраняются. Для течения v1 исходная карта направления берётся из модели или локального набора; для v2 карта генерируется из сети. **Скачать настройки / Открыть настройки** — лёгкая JSON-копия этих же параметров без карт, а не полный набор.

При повторной загрузке модели комнаты настройки применяются автоматически. Сохранение доступно владельцу проекта/комнаты согласно `can_manage_room_models`; чтение ограничено участниками комнаты. Версия документа защищает от перезаписи устаревшим состоянием. Загруженные позже модели получают только свои настройки. После сетевого сбоя восстановление повторяется при событии online. Локальную модель перед сохранением настроек следует синхронизировать с комнатой.

Backend: `supabase/migrations/20260924000100_room_material_settings.sql`, установлен с разрешения владельца 2026-09-24. Новая миграция не нужна. Настройки лежат в отдельной JSONB-строке `room_material_settings`, отдельно от GLB. Старые документы с встроенными картами читаются для совместимости; при следующем сохранении все строки, включая ранее сохранённые настройки других моделей, преобразуются в параметры без изображений.

## Полный набор на компьютере

В разделе **Набор материалов на компьютере** выберите модель и нажмите **Сохранить набор на диск**. Один файл `.lpmat` содержит все уникальные материалы выбранной модели, включая неизменённые, карты, параметры и течение воды. Геометрия и HDRI сцены не входят. Сохраняется редактируемая версия, даже если включён просмотр исходных материалов. Скачивание само по себе не помечает материалы изменёнными и ничего не пишет в комнату.

Чтобы перенести материалы:

1. Откройте модель и выберите её в разделе набора.
2. Нажмите **Открыть набор с диска** и выберите файл `.lpmat`.
3. Проверьте число совпадений и пропусков, затем нажмите **Применить**.

Набор работает и для локальных моделей без проекта, без облачного доступа. Сопоставление идёт по именам материалов (Unicode NFKC, без учёта регистра и крайних пробелов), а не ID модели или порядку материалов. Для повторяющихся имён дополнительно проверяются пути объектов в иерархии, слоты, трансформации и размеры геометрии: это позволяет восстановить одноимённые материалы в той же модели. Если такой привязки нет или она неоднозначна, материалы пропускаются и перечисляются. Материалы без пары сохраняют вид. Подготовка всех совпавших материалов завершается до замены назначений. Ошибка, повреждённый файл, отмена, смена комнаты или модели не применяют набор частично. Исходные материалы доступны для сравнения.

**Локальные карты не загружаются в облако.** При следующем открытии модели их нужно снова открыть из `.lpmat`, если их нет в исходном GLB. Применение полного набора восстанавливает параметры, записанные в этом файле; чтобы отдельно перенести более поздние настройки комнаты поверх него, сначала скачайте JSON настроек, затем откройте набор и этот JSON. Для актуальной полной копии сохраняйте новый `.lpmat` после редактирования.

Переносятся PBR и unlit, 22 слота карт, Z-приоритет, прозрачность, стороны и вода. IOR=3 сохраняется напрямую. Для воды восстанавливаются runtime WebGPU/WebGL, скорость, пауза, карта направлений и сеть ветвления. Течение остаётся в координатах/UV исходной модели; при изменении русла или привязки его нужно отредактировать. Произвольный сторонний код ShaderMaterial не сериализуется и не исполняется из файла.

Формат `.lpmat`: сигнатура `LPMAT001` (8 байт), длина JSON uint32 little-endian (4 байта), UTF-8 JSON `{pack, assets}`, затем PNG. Индекс содержит относительные смещения, размеры и SHA-256 изображений. Это контейнер без сжатия, а не ZIP: PNG уже сжаты. Чтение и запись не требуют загрузки библиотек или сетевых запросов. Blob-срезы позволяют не превращать всю текстурную библиотеку в огромную base64-строку. Проверяются целостность индекса, наличие карт, подпись и размеры PNG, хеш каждой используемой карты.

Изображения сохраняются в исходном разрешении до 8192 px; одинаковые изображения хранятся один раз. Сохраняются UV-канал, повторение, смещение, поворот, центр, матрица, flipY, wrapping и цветовое пространство каждой карты. Пределы: 4096 материалов, 32 МиБ на PNG, 512 МиБ всех изображений, 8 МиБ JSON. Пока файл готовится, миниатюры и автоматическая перерисовка воды временно приостанавливаются, не меняя скорость и паузу. После завершения/отмены/ошибки/закрытия редактора анимация возобновляется.

Прежняя библиотека полных наборов в проекте отключена. Неустановленная миграция `project_material_packs`, её runtime и SQL-тест удалены; изменений в действующей базе для этого перехода нет.

## Проверка

`npm run ci:verify`: общие проверки, `smoke-material-editor.mjs` (общие материалы, исходные, настройки, привязка к поверхности при rebase, ветки, устаревшие ответы комнаты), `smoke-material-packs.mjs` (локальный файл, UI загрузки/сохранения/сопоставления, новые ID и порядок материалов, карты и их дедупликация, IOR=3, вода v1/v2, параметры комнаты без изображений, сохранение текущих карт, повреждённые файлы, отмена и пипетка). WebGPU проверяется при наличии адаптера, дополнительно используется аппаратная проверка на Mac. SQL: `supabase/tests/material-settings.sql` в workflow Database Permissions.
